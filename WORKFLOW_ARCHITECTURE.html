Step 6: Containerization & Nebius AI Serverless Endpoint Deployment

Production container workflow using Dockerfile, nebius registry configure-docker, and nebius ai endpoint create.

# 1. Authenticate Docker with Nebius Container Registry
nebius registry configure-docker

# 2. Build, tag, and push the Streamlit 3D Simulation Studio image
docker build -t physics-auditor:v1 .
docker tag physics-auditor:v1 <your-registry-id>/physics-auditor:v1
docker push <your-registry-id>/physics-auditor:v1

# 3. Deploy as a managed HTTPS Nebius Serverless Endpoint on port 8501
nebius ai endpoint create \
  --name physics-fidelity-auditor \
  --image <your-registry-id>/physics-auditor:v1 \
  --container-port 8501 \
  --platform cpu-d3 \
  --preset 4vcpu-16gb \
  --public \
  --env NEBIUS_TOKEN_FACTORY_KEY=$NEBIUS_TOKEN_FACTORY_KEY \
  --env TAVILY_API_KEY=$TAVILY_API_KEY
